Compact independent skin selection for solo and multiplayer. Each player's skin choice persists between missions, campaign co-op sessions, hosts and game restarts. Game/Mods/Favorites filters, name search and personal favorites. Main-menu options for language, shortcut and saved-skin recovery. English / Portugues. Open Skins from the pause menu or set your own shortcut. AGPLv3 or later with an additional Teardown runtime permission. Readable source included.

Source code:
https://github.com/Luiz-AVcruz/Open-Skin-Selector-OSS
